
PIPELINE ASPECT-BASED SENTIMENT ANALYSIS (ABSA) UNTUK KINERJA PONDOK PESANTREN

1. INPUT DATASET
- masukan nama file berupa Excel (.xlsx) dengan manual
- Kolom yang dibaca: "kalimat" (ulasan) dan "ponpes" (nama pondok pesantren)

2. WORDCLOUD
- Tampilkan WordCloud dari kolom "kalimat" per ponpes

3. PENENTUAN ASPEK SECARA MANUAL
- Daftar aspek:
  - Kualitas Guru
  - Fasilitas
  - Lingkungan
  - Kegiatan Pondok
  - Pembinaan Karakter
  - Prestasi
  - Akademik
  - Motivasi/Spiritual
  - Sosial
  - Umum
- Kalimat dicocokkan dengan kamus kata dasar (hasil stemming)
- Satu kalimat hanya memiliki satu aspek dominan (jika lebih dari satu, ambil satu saja)

4. SENTIMEN
- Gunakan model HuggingFace: taufiqdp/indonesian-sentiment
- Prediksi sentimen berdasarkan kalimat

5. PEMBENTUKAN DATASET BARU
- Format output dataset:
  - kalimat
  - aspek
  - sentimen

6. PELATIHAN MODEL RNN
- Split data: 80% training, 20% testing

7. EVALUASI
- Tampilkan confusion matrix
- Classification report (precision, recall, f1-score)
- Hitung akurasi dan f1-score rata-rata

8. VISUALISASI PER ASPEK DAN PESANTREN
- Distribusi sentimen untuk tiap aspek di masing-masing pondok pesantren

CATATAN:
- Kode disusun dalam Google Colab tanpa fungsi tambahan.
- Setiap langkah memiliki output yang dapat dilihat langsung.
