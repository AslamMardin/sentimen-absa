### Spesifikasi Teknis:
**Data Input:**
- Format: EXCEL dengan kolom [no,nama,kalimat,ponpes]
- Contoh data:
  "Pelajarannya sangat mendalam", "Kualitas_Guru", "positive"
  "Asrama perlu renovasi", "Fasilitas", "negative"

**Preprocessing:**
1. Tokenisasi bahasa Indonesia 
2. Stemming dengan Sastrawi
3. One-hot encoding untuk aspek
4. Padding sequence

**Arsitektur Model:**
- Embedding Layer (dimensi 256)
- Bidirectional LSTM (128 unit)
- Attention Mechanism
- Dense Layer untuk klasifikasi aspek (11 kelas)
- Multi-task learning untuk sentimen (3 kelas)

**Pelatihan:**
- Optimizer: AdamW
- Loss Function: 
  - Aspek: Categorical Crossentropy
  - Sentimen: Weighted Crossentropy
- Metrik: F1-score per aspek

**Evaluasi:**
- Confusion matrix multi-label
- Laporan klasifikasi per aspek
- Visualisasi learning curve
